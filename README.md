**My way of learning in public.**

I'm learning Rust from scratch, one session at a time. These are my real session notes — including the mistakes I made, the compiler errors I triggered, and what each one taught me. If you're learning Rust too, maybe my wrong turns save you a few of your own.

## How I work

Each session I learn a concept, predict what code will do before running it, write real code, and let the compiler catch my mistakes. The errors are the best part — every note file includes the actual compiler output and the lesson it taught.
